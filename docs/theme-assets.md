# Theme artwork

The red stadium background is original, procedural Canvas artwork.

`app/src/main/res/drawable/fc_bayern.xml` is a vector conversion of the FC Bayern
München 2024 crest, sourced from:
https://commons.wikimedia.org/wiki/File:FC_Bayern_M%C3%BCnchen_logo_(2024).svg

The source credits FC Bayern München / fcbayern.com and classifies the logo as
PD-textlogo with trademark restrictions. The crest is not covered by this
repository's MIT license. Its inclusion does not imply club endorsement.
