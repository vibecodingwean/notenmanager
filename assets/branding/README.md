# NotenManager branding

`notenmanager.png` is the selected 1254 × 1254 book and path illustration. It is stored as a clean RGB PNG without source metadata. The Android artwork resource uses identical image bytes. The adaptive foreground preserves the complete artwork with a 10% inset; Android supplies the outer launcher mask for both regular and round icons.

Android themed launcher icons and notifications use a simplified white vector silhouette of the same book and path motif. Internal resource names stay unchanged for compatibility. The app package remains `com.streberalarm.app`.
