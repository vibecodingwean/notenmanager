# StreberAlarm branding

`streberalarm.png` is the full 1254 × 1254 illustration used for the app icon: a smiling character with glasses, a raised index finger and a red siren ring. The Android artwork resource contains the same image bytes. The adaptive foreground uses a 10% inset; the launcher supplies its own outer mask.

`streberalarm-symbol.svg` provides the simplified finger and rotating red/blue arrows. The 512px and 1024px PNGs are previews of this vector. Android uses monochrome vector variants for themed launcher icons and notifications.

Platform-specific iOS exports can be derived from these assets when the iOS application is implemented.
