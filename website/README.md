# NotenManager website

German static product website with screenshots, tutorial chapters, privacy information and contact details.

Serve `public/` with a static HTTP server. The video player requires support for HTTP byte-range requests. The separately supplied tutorial belongs at `public/assets/tutorial-v2.mp4`; captions and music attribution are included. No application binaries are distributed by this website.

The site layout is adapted from the EchoScribe website; its MIT license is retained in `public/SITE-LICENSE.txt`. Tutorial music attribution is in `public/assets/MUSIC-LICENSE.txt`.

Canonical website: https://app.wean.de/notenmanager/. Retain redirects from the former /streberalarm/ route. The preserved v2 tutorial and screenshots show the earlier StreberAlarm version and are identified as historical captures on the page and in the player. Captions preserve the actual spoken wording.
